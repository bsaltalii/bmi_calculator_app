# ⚖️ BMI Calculator App

*BMI Calculator App* is a mobile application built using Flutter that allows users to calculate their Body Mass Index (BMI) based on height and weight inputs. It visually categorizes the result into underweight, normal, overweight, or obese.

---

## 🎯 Purpose

This app was developed as a practical and educational tool.  
It aims to promote health awareness by helping users understand their BMI and general health category in an intuitive interface.

---

## 🧩 App Architecture

Structured using Flutter’s widget-based composition for clean and scalable code:

| 🧱 Component      | 📌 Description                                |
|------------------|-----------------------------------------------|
| *Main*           | App entry point and routing                   |
| *Input Widgets*  | Custom sliders and input fields for height/weight |
| *Result Screen*  | Displays the calculated BMI and category      |
| *Logic Helper*   | Contains BMI calculation and classification   |

---

## 🚀 Features

<ul>
  <li>🧮 <strong>BMI Calculation</strong>: Instantly calculates your BMI based on height and weight.</li>
  <li>📊 <strong>Visual Results</strong>: Color-coded and labeled result screen for health categories.</li>
  <li>📱 <strong>Mobile Responsive</strong>: Designed to work seamlessly on Android and iOS devices.</li>
  <li>🎯 <strong>Interactive UI</strong>: Intuitive sliders and responsive design elements.</li>
</ul>

## 📦 Installation

### Prerequisites

•⁠  ⁠Flutter SDK (latest stable version)  
•⁠  ⁠Dart SDK  
•⁠  ⁠Android Studio, VS Code, or any Flutter-compatible IDE  
•⁠  ⁠Physical device or emulator

### Steps

```bash
# Clone the repository
git clone https://github.com/bsaltalii/bmi_calculator_app.git

# Navigate to the project directory
cd bmi_calculator_app

# Install dependencies
flutter pub get

# Run the app
flutter run
```
